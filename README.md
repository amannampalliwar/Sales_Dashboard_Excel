# Sales_Dashboard_Excel

# 📊 Business Sales Analysis Dashboard using Excel

## 📌 Project Overview

This project focuses on analyzing business sales data and transforming raw sales records into meaningful insights through an interactive Excel dashboard. The dashboard helps visualize sales performance, product profitability, regional contributions, salesperson effectiveness, and customer payment preferences.

Using Microsoft Excel, various data analysis and visualization techniques were applied to support business decision-making and performance monitoring.

---

## 🎯 Objectives

* Analyze overall sales performance.
* Identify top-performing products and regions.
* Evaluate salesperson contributions.
* Monitor monthly sales trends.
* Analyze payment mode distribution.
* Create an interactive dashboard for business reporting.

---

## 📂 Dataset Information

The dataset contains **1000+ sales records** with the following fields:

* Order ID
* Order Date
* Region
* Product
* Salesperson
* Quantity
* Sales Amount
* Cost Amount
* Profit
* Payment Mode

## 📈 Analysis Performed

### Region-wise Sales Analysis

* Compared sales performance across North, South, East, and West regions.
* Identified the highest-performing sales region.

### Product Profitability Analysis

* Evaluated profit generated by each product category.
* Determined the most profitable product.

### Salesperson Performance Analysis

* Compared sales generated by different salespersons.
* Identified top-performing employees.

### Monthly Sales Trend Analysis

* Analyzed sales fluctuations across different months.
* Identified peak sales periods.

### Payment Mode Analysis

* Studied customer payment preferences.
* Compared usage of different payment methods.
